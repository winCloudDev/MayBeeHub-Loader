📌 Overview

MayBeeHub (MBH) is a Roblox script loader designed with a clean interface and a user-friendly experience using the Rayfield UI system.

✨ Features

- 🎨 Rayfield UI System
- ⚡ Lightweight Loader
- 📦 Remote Script Loading
- 🔄 Easy Script Updates
- 🖥️ Clean User Interface
- 🛠️ Simple Execution

📥 Installation

Step 1 — Open Your Supported Environment

Open a compatible Roblox development or testing environment.

Step 2 — Copy the Loader

Copy the following Lua code:

loadstring(game:HttpGet("https://raw.githubusercontent.com/winCloudDev/MayBeeHub-/refs/heads/main/MBH%20LOADER.lua"))()

Step 3 — Execute

Run the code in an environment where remote script loading is supported.

Step 4 — Open MBH Loader

Wait for the loader to initialize and display its interface.
